# Code of Conduct

PyTextAD follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions; criticise
ideas, not people; and help make the project welcoming to everyone, whatever their
background or level of experience. Harassment and personal attacks are not tolerated.

Problems can be reported to the maintainer, Yang Cao, through GitHub
([@charles-cao](https://github.com/charles-cao)). Reports are handled confidentially.
